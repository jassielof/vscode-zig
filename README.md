# Zig Language Support for Visual Studio Code

[![VSCode Extension](https://img.shields.io/badge/vscode-extension-brightgreen)](https://marketplace.visualstudio.com/items?itemName=ziglang.vscode-zig)
[![Open VSX Version](https://img.shields.io/open-vsx/v/ziglang/vscode-zig?color=brightGreen)](https://open-vsx.org/extension/ziglang/vscode-zig)

Support for Visual Studio Code for the [_Zig programming language_](http://ziglang.org/).

![Syntax Highlighting, Code Completion](./images/example.png)

## Features

- Install and manage Zig versions
- Syntax highlighting
- Basic compiler linting
- Automatic formatting
- Run/Debug Zig programs
- Run/Debug tests
- Optional [ZLS language server](https://github.com/zigtools/zls) features
  - Completions
  - Goto definition/declaration
  - Document symbols
  - ... and [many more](https://github.com/zigtools/zls#features)
